# Assistant

Talking to the inventory from a desk, through an MCP client.

## S-MCP-01 Connect an assistant

A Scouter opens Settings, taps "Connect an assistant", and pastes the token into their MCP client. It appears in their
device list beside their phone.

- The token is shown once
- No Admin is involved
- Revoking it is the same as revoking a lost phone

Covers: FR-MCP-01, FR-MCP-02, FR-USR-14

## S-MCP-02 Plan a camp by asking

A Scouter asks for a reservation for Fall Camp, the first weekend of October, with the same gear as last year plus two
tarps. The assistant duplicates last year's reservation, adds the tarps, and reports that one tent is already booked
that weekend.

- The reservation appears in the app on every phone at the next sync
- The clash is named, as the app would name it
- History shows the Scouter, via the assistant

Covers: FR-MCP-03, FR-MCP-05, FR-MCP-06, FR-RES-10

## S-MCP-03 What it cannot do

The Scouter asks the assistant to invite a new volunteer. It cannot; that is an Admin's job in the app.

- No user, setting, location, type, or code change is offered

Covers: FR-MCP-04
