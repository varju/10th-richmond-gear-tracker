# Reservations

Planning a camp, then packing for it. The value is the packing checklist, not the calendar.

## S-RES-01 Plan a camp

A Scouter creates a reservation for Fall Camp with a date range and a list of gear. Another Scouter adds the tarps the
next day.

- An event name, dates, and items are enough
- The list can be built by search or by browsing
- Anyone signed in can change any reservation; there is no owner

Covers: FR-RES-01, FR-RES-16

## S-RES-02 Pack for the camp

On the Friday, a Scouter opens the reservation. It becomes a scanning session showing everything still unscanned.

- The event name is taken from the reservation, not typed again
- Each scan ticks an item off the list
- The remaining list is always visible
- Nothing is checked out unless it is scanned, or ticked off the list if it has no sticker

Covers: FR-RES-02, FR-RES-03

## S-RES-03 Leave something behind

The forecast is dry, so nobody takes the tarps. Finishing the session names what was not scanned.

- Unscanned items are named at the end
- The session can be finished anyway

Covers: FR-RES-04

## S-RES-04 Take something extra

Someone grabs a second stove that was not on the list. They scan it and it joins the check-out, and the reservation.
Next year's Fall Camp, duplicated from this one, has two stoves.

- Unlisted items are appended with no warning and no extra tap
- The reservation's gear list grows to match what went out

Covers: FR-RES-07, FR-RES-10

## S-RES-07 Gear that left before the plan did

A patrol took three tents on Thursday with no event set. On Friday the Quartermaster opens the reservation and sees them
as unscanned. One tap each says they are already with us.

- The movement is corrected, never rewritten
- The items join the gear list
- Nothing is checked out or in

Covers: FR-RES-17, FR-OUT-16

## S-RES-05 Two camps, same weekend

A second reservation claims tents already booked for Fall Camp. The app names the clash.

- The conflicting event is named
- Repeat trips can be duplicated rather than rebuilt

Covers: FR-RES-05, FR-RES-10

## S-RES-06 Coming home

Gear returns over the following week, in pieces, carried by whoever had room. There is no return session.

- Returns use the ordinary check-in
- The reservation is not involved

Covers: FR-OUT-06, FR-OUT-08
